## 鼠标进不去或镜头不动

使用独立游戏窗口。先 Alt+Tab 选中游戏，再点一下游戏画面或按右键，进入鼠标控制。切出窗口会暂停，切回后的第一次点击可恢复。

若仍不响应，**F8 切换兼容鼠标模式**，或在暂停页点击对应按钮，再返回游戏。**F10 暂停并释放指针**，Esc / Tab 也可暂停；底部显示模式和锁定状态。兼容选择保存在本游戏 `.local` 中。镜头仍只随鼠标即时转向，右移向右转，上移抬头，保持第三人称。

暂停页有“保存并退出”，标题页可直接退出到桌面，窗口关闭也能保存退出。保存失败时提供明确退出选项，已有存档保留。若窗口显示“未响应”或画面完全停止，还需要排查程序卡住，不能直接断定是鼠标硬件问题。
