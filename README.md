## 可以反复玩的循环

村南找顾伯按 E，选择采药、猎妖或勘察委托。到野外采药、战斗、勘察，靠近掉落的兽丹、金币或草药束按 E 拾取，再回村交付、交易、补给并强化飞剑。交付后可以再接，妖兽和野生灵草可刷新。

坊市有顾伯、药师沈娘、行商陆舟三名 NPC。金币可用于补给、灵种和最多八次飞剑强化。按 4 使用养元丹，5 使用回灵散；M 地图可切区域总览，查看四片新增猎场。外围新增十二只妖兽，分妖狼、山豕、毒蛛、石妖四类；可行走面积约为原来的五倍。

镜头只用鼠标即时转向：右移向右转、上移抬头；右键恢复锁定，滚轮调节远近。仍为第三人称，键盘负责移动、技能和功能。打开菜单时鼠标自由操作，切换窗口自动暂停。
