## 覆盖更新

退出游戏。先在 D/E 盘备份原 Qinglan/.local/saves，再将更新包里的 Qinglan 文件夹合并到旧目录，覆盖同名工程文件。保留原 tools/godot 和 .local，不要解压成 Qinglan/Qinglan。

运行原来的 Start-Game.cmd，标题显示 v0.2 后选择继续旅程。旧存档会自动迁移，且先备份为 journey.json.v1.bak。不要创建新角色覆盖旧旅程。

新增御剑三连、护体术、火弹术、灵蛛、镇府石卫、三柱解阵、遗府传承、个人洞府、储物、三块灵田、修炼与三套布置。

这是占位美术的玩法原型，Windows 本机帧率尚待实测。所有包都应下载和解压到 D/E 盘。
