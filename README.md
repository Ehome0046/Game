## 怎样认领自己的洞府

开局即可认领，不需要功法、突破或通关遗府。村口南侧绕过房屋，向西过桥，绕到无主石室正门按 E。认领后 H 才能脱战回府。

M 查看地图，N 显示/隐藏金色引路点。右侧安家卡片始终说明条件和路线；地图显示你的位置、无主石室、小桥与灵田。跟着金色路点手动走，到门前按 E。

洞府内右侧箱子 E 储物，左侧蒲团 E 调息/G修炼；屋外北侧三块灵田 E 播种与收获。此补丁调整了桥口与门前路线，并保留已有角色和存档。

原有玩法、镜头动作与新增导航检查通过，导航测试使用真实物理移动走到入口并完成认领，另已检查地图和引路截图。云端显示验证采用 Linux X11/OpenGL，Windows 本机仍需试玩确认。
