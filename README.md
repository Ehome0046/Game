## 本次改动

- **立体地形**：外域有实际可行走的山坡、高岭与石径，人物、妖兽、掉落、预警和引路点随地面高度放置；旧档恢复到当地地面。建筑和重要入口保留平整基础。
- **人物与反馈**：修正脸部和施法手臂朝向，避免采集和施法姿态重叠；增加手部与五官细节、翻滚、受击偏转、图标提示和短促音效。洞府灯具补齐顶座、吊链和灯框。
- **境界与功法**：U 查看炼气二 / 三层突破、剑修 / 法修路线及三级功法研习。猎妖、制作和蒲团修炼获得修为，突破给进阶装备；材料不足不扣费。静心台或室内蒲团旁脱战后主动突破。
- **战斗操作**：左键短按普通御剑，按住至少 0.65 秒再松开发射蓄力御剑；Q / 1 保留普通连击。F 精准护体可挡住一次攻击并接反击，空格有完整翻滚动作。
- **野外宝箱**：E 开格子，上方取物、下方存材料与补给，Shift 整叠，可全部取出。箱盖有动作，未取物品存档保留；秘境遗留物品可免费取回。
- **装备简化**：B 用图标和分类查看当前穿戴与换装增减，选一件点“换上这件”，或“一键穿戴推荐”。温养、升品、分解和出售收进“温养与整理”，旧装备继续保留。

原有宗门剧情、贡献委托、洞府自由布置、灵田、炼丹、遗府、秘境与坊市继续使用。数字 4～8 是丹药，F8 是鼠标兼容模式；F10 释放指针，切回窗口后单击恢复。
