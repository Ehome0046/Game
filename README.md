## 装备、炼丹与探索循环

猎妖掉装备和药材，E 拾取，B 查看飞剑、衣服、护符并穿戴。九种装备分凡品、灵品、玄品，改变实际属性与部分外观；可卸下分解为灵铁，或带到村南陆舟身边出售。装备背包满时，地面装备会保留。

洞府门口 E 入室，丹炉 E 选择丹方，炼器案 E 制作飞剑。可炼养元丹、回灵散、聚气丹，矿洞图谱解锁灵铁飞剑。完成才扣材料，E / 移动可取消。4 / 5 用补给，6 用聚气丹；沈娘收药与售药，顾伯可反复接药品委托。

T 切换探索指引，M 查看区域总览。村西落霞药谷采赤霞花与凝露草；村东青石矿洞可走入采矿、开宝箱找图谱；北面望月秘境需炼气一层和一枚兽丹进入，内有玄品装备、聚气丹方和返程传送点。宝箱游玩 180 秒恢复，暂停与离线不计时。

新地点加入石径、路牌、矿洞轨道和木支架、晶簇、草丛、水面波纹与轻微环境声。可以采药 / 猎妖 → 装备 / 炼丹 / 制作 → 交易与委托 → 补给强化 → 再次探索。
